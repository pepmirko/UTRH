## Scientific scope

The strong cellular UTRH is not claimed to be directly testable with the currently qualified public cellular corpus. The registered analyses test local and cross-disease consequences of scalar temporal rescaling, including AFT/shape invariance, prion rate-modifier structure, and threshold-aligned polyQ transfer.
